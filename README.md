# Экономический Discord-бот

Работает в канале #корзина (ID в config.py). /room — ещё и в канале 1558028581521854585.

## Команды
- Экономика: /timely (ежедневная награда), /balance, /give (перевод с подтверждением, комиссия сверху),
  /history, /top (монеты, голосовой онлайн, задания, сообщения — до 25 мест)
- Магазин: /shop — баннер (pics/shop.png), роли, кастомные комнаты, кнопка «Создать свою роль»
- Инвентарь: /inventory — картинка-карточка + хранилище ролей; кнопки «Инвентарь» (предметы из кейсов
  и монеты) и «Управление ролью» (название, цвет, продажи и заработок)
- Кейсы: /case — картинка с кейсами, кнопки открытия (гифка gifs/case.gif → результат)
- Любовные комнаты: /marry, /devorce; «Любовный профиль» — кнопка в /profile (продлить, скинуться в баланс
  комнаты, развестись). Предложение действует 24 часа. Если в копилке хватает денег — комната продлевается сама.
- Кастомные комнаты: покупка в /shop, управление — /room
- Игры: /duel /coinflip /slots /roulette /log /miner (сапёр 5x4)
- Профиль и задания: /profile, /quests
- Админ (роль из config.ADMIN_ROLE_ID): /panel
- Кейсы (ID из config.CASE_ADMIN_IDS): /panel_case

## Автоматически
- Кейсы выпадают за сообщения (не чаще раза в 30 сек.) и за каждую минуту в голосовом.
- В 00:00 (UTC+7) самый активный в голосовых получает награду, сообщение с его профилем
  приходит в канал config.VOICE_TOP_CHANNEL_ID, прошлое сообщение удаляется.
- Задания обновляются в 00:00 (UTC+7).

- Роль или комната, удалённая администратором в Discord, сразу удаляется и из базы (cogs/sync.py).

## Запуск
1. pip install -r requirements.txt (нужен discord.py 2.4 или новее)
2. Файл .env с DISCORD_TOKEN и GUILD_ID
3. В Developer Portal -> Bot включи «Server Members Intent»
4. python bot.py

Боту нужны права: Управление ролями, Управление каналами, Перемещение участников, Прикреплять файлы.
Роль бота должна стоять выше всех ролей, которые он выдаёт (роли магазина, кейсов, комнат).

## Обновление без потери монет
Все монеты, роли, комнаты и статистика лежат в economy.db (рядом с bot.py).
1. Останови бота и скачай economy.db себе (резервная копия).
2. Залей новые файлы поверх старых. НЕ заменяй economy.db и .env.
3. Запусти бота — новые таблицы добавятся сами, старые данные не трогаются.
